# 無認証運用の前提条件・運用範囲設計書

**Task**: T078 (FR-013)  
**Status**: Draft  
**Last Updated**: 2026-03-04

---

## 1. 概要

本プロジェクトは **デモンストレーション・実験用の無認証ガジェット** として設計されています。認証機構を持たず、信頼できるネットワーク環境での動作を前提とします。本設計書は、その前提条件、運用範囲、セキュリティ考慮事項を明記します。

**重要**: 本プロジェクトは **インターネット公開不可**、**複数ユーザー共有環境不可**

---

## 2. セキュリティ前提条件

### 2.1 ネットワーク環境

| 前提条件 | 要件 | 理由 |
|---------|------|------|
| **ネットワーク分離** | ローカルLAN のみ | USB-UART による直接接続、または同一サブネット内 |
| **デバイス管理** | Raspberry Pi 5 物理管理者が限定 | デバイス盗難時のデータ保護は対象外 |
| **ユーザー認証** | 信頼できるユーザーのみ想定 | 悪意のあるユーザーからの保護は対象外 |
| **データ暗号化** | なし | ローカル LAN のため通信盗聴リスク低い |
| **ログ監査** | ローカルログのみ | 外部への送信なし |

### 2.2 想定ユースケース

✅ **許可された使用方法**:
- 大学の研究室での学習教材
- デバイス開発のためのプロトタイプ
- 社内デモンストレーション（非公開）
- IoT 学習用キット

❌ **禁止される使用方法**:
- インターネット経由での公開サービス
- 不特定多数のユーザーがアクセスする環境
- クラウド連携による外部データ送信
- 本番環境での使用

## 3. セキュリティアーキテクチャ

### 3.1 通信層

```
┌─────────────────────────────────────┐
│ VS Code + GitHub Copilot (User)     │
│ (ローカルマシン)                      │
└────────┬──────────────────────────────┘
         │ stdio (プロセス内通信)
         │ 認証なし（プロセス分離によるセキュリティ）
         ↓
┌─────────────────────────────────────┐
│ Raspberry Pi 5 (ローカル LAN)        │
│ MCP ゲートウェイ (Python)             │
│ - 認証トークンなし                   │
│ - ローカルホストのみリッスン           │
└────────┬──────────────────────────────┘
         │ Serial (USB-UART)
         │ 認証なし（物理接続のみ）
         ↓
┌─────────────────────────────────────┐
│ M5StickC Plus2 (有線接続)            │
│ - パスワード保護なし                  │
│ - ファームウェア暗号化なし             │
└─────────────────────────────────────┘
```

### 3.2 認証レイヤーの削除根拠

1. **stdio ベース通信**: VS Code ← → MCP (子プロセス)
   - プロセス分離によるセキュリティ（OS レベル）
   - トークン認証不要（ユーザー=ローカルアカウント）

2. **USB-UART ベース通信**: Raspberry Pi ← → M5Stick
   - 物理層接続（盗聴困難）
   - シリアル番号による暗黙の認証

3. **デバイス側（M5Stick）**:
   - 認証コマンドなし
   - 任意のシリアルフレームを受け入れ
   - **責務**: コマンド検証（形式チェック）のみ

## 4. 信頼境界（Trust Boundary）

```
┌─── 信頼境界 ────────────────────────────────────────┐
│                                                      │
│ ┌────────────────┐  ┌────────────────┐             │
│ │ VS Code        │  │ Raspberry Pi    │             │
│ │ + Copilot     │→ │ (MCP Gateway)   │             │
│ └────────────────┘  └────────────────┘             │
│         ↓ stdio              ↓ serial                │
│ ┌────────────────┐  ┌────────────────┐             │
│ │ Local Account  │  │ M5StickC Plus2 │             │
│ │ (認証: OS)     │  │ (認証: 物理結線) │             │
│ └────────────────┘  └────────────────┘             │
│                                                      │
└─────────────────────────────────────────────────────┘

信頼内: ローカルユーザー + ローカルネットワーク
信頼外: インターネット + 未認証ユーザー

❌ 信頼外へのトラフィック: なし
✅ 信頼内のみでの完結: はい
```

## 5. リスク評価

### 5.1 シナリオ別検討

| リスク | 発生条件 | 影響度 | 対策 |
|--------|--------|--------|------|
| **USB ポート改ざん** | 物理的な USB-UART の交換 | 高 | 物理管理者による監視 |
| **Raspberry Pi 盗難** | デバイス紛失 | 高 | ローカルバックアップのみ（外部非保存） |
| **ローカル LAN スキャン** | 同一 LAN 内の不正アクセス | 中 | ファイアウォール（未実装、今後検討） |
| **コマンドインジェクション** | malformed シリアルコマンド | 低 | CRC チェック + 入力検証 |
| **メモリリーク** | 大量コマンド送信 | 低 | リングバッファ制限 |

### 5.2 対策一覧

| 対策 | 実装済み | 今後実装 | 非対象 |
|-----|--------|---------|-------|
| **入力検証** | ✅ (CRC, フレーム形式) | - | - |
| **エラーハンドリング** | ✅ (ER-xxx) | - | - |
| **ローカルログ記録** | ✅ (全リクエスト) | - | - |
| **タイムアウト** | ✅ (5秒 SLA) | - | - |
| **OS レベルアクセス制御** | - | ✅ (Phase 4) | - |
| **TLS/SSL 通信** | - | - | ❌ (LAN のみなので不要) |
| **トークン認証** | - | - | ❌ (信頼内通信のため不要) |
| **ファームウェア署名** | - | - | ❌ (研究用プロトタイプ) |

## 6. 運用ガイドライン

### 6.1 推奨される運用方法

✅ **すべきこと**:

1. **物理的アクセス制限**
   - Raspberry Pi = 管理者のみ物理アクセス可能な環境
   - USB-UART ケーブル = 改ざん検査可能な配置

2. **ローカルネットワーク限定**
   - Raspberry Pi SSH = ローカルホスト (127.0.0.1) のみリッスン
   - MCP stdio = VS Code 子プロセス (ローカル)

3. **ユーザー登録**
   - 利用者はローカル OS アカウント保持者
   - ゲストアカウント = 使用禁止

4. **ログ監視**
   - 毎月のログレビュー（異常検知）
   - エラーログの保存期間 = 6 ヶ月

### 6.2 禁止事項

❌ **してはいけないこと**:

1. **インターネット公開**
   - Raspberry Pi を WAN に直結しない
   - SSH ポートを外部ネットワークに公開しない

2. **マルチユーザー共有**
   - 複数ユーザーが同時アクセス → 未サポート
   - ユーザー認証機構なし

3. **データ外部送信**
   - ログをクラウドに送信しない
   - 履歴をリモートサーバーに同期しない

4. **ファームウェアカスタマイズ**
   - 公式ファームウェア以外の使用禁止
   - 改造ファームウェア = サポート対象外

## 7. デフォルト設定

### 7.1 Raspberry Pi 設定

```bash
# MCP ゲートウェイアクセス
- リッスンポート: localhost:9000 (stdio のみ)
- CORS: なし
- SSL/TLS: なし
- 認証: なし

# ログファイル
- 保存先: /home/pi/m5-gateway/logs/
- レベル: INFO (デバッグ時は DEBUG)
- ローテーション: 月間、保持期間 6 ヶ月
```

### 7.2 M5Stick 設定

```cpp
// ファームウェア設定
#define ENABLE_AUTH 0              // 認証なし
#define SERIAL_BAUD 115200         // 固定
#define SERIAL_TIMEOUT_MS 5000     // 5 秒
#define CRC_CHECK_ENABLED 1        // CRC チェック有効
```

## 8. インシデント対応

### 8.1 想定インシデント

| インシデント | 兆候 | 対応 |
|-----------|------|------|
| **Raspberry Pi 盗難** | デバイス不明 | ローカルバックアップ喪失;外部バックアップなし |
| **USB ケーブル切断** | ER-TIMEOUT 頻発 | ケーブル物理確認、交換 |
| **ファームウェア破損** | 起動失敗 | PlatformIO でリセット + 再書き込み |
| **ローカルネットワーク侵害** | 不正コマンド受信ログ | ネットワーク管理者に報告、緊急停止 |

### 8.2 緊急停止手順

```bash
# デバイス即座停止
1. Raspberry Pi の電源を切る (sudo poweroff)
2. M5Stick の電源を切る (USB-UART 切断)
3. 物理的に隔離 (LAN から抜く)
4. 管理者に報告
```
